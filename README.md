# Findom Debt Servitude App

A small Next.js fantasy debt tracker for roleplay.

## Features

- Live principal / interest / penalties / total owed
- Make weekly payments (LKR 15,000)
- Add late fees and daily penalties
- Increase principal
- Activity log
- Full formal-looking debt contract text
- Dark theme

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push this folder to a GitHub repository
2. Import the repo in Vercel
3. Deploy (no extra configuration needed)

Or use the Vercel CLI:

```bash
npm i -g vercel
vercel
```

## Notes

This is a **fantasy / roleplay** application only.  
It has no legal force.
